# Магазины

В лавках используется обычный каталог товаров: игроки видят ассортимент, фильтры, поиск, характеристики, цены и наличие. Покупка выполняется через серверное событие `shop:purchase` с серверной проверкой золота и наличия.

Мастер видит управление ценами, остатками и добавлением пользовательских товаров.

Диалог с ИИ для магазинов отключён: клиентская форма чата и серверное событие `shop:chat` удалены. Другие функции мастера и игры не затрагивались.

# Магазины D&D — исправленный пакет

## Что входит
- Кузница — оружие.
- Бронная мастерская — броня, щиты, сапоги и перчатки.
- Библиотека — книги заклинаний.
- Рынок и обычная лавка — полный ассортимент.
- Восемь фиксированных локаций получили отдельную бронную мастерскую.
- Каталог: 492 предмета — 180 видов оружия, 144 вида брони, 36 щитов, 6 сапог, 6 перчаток и 120 книг. По 82 позиции каждого из шести королевств.
- На листе персонажа есть отдельное поле «Золото». У старых персонажей оно создаётся со значением 0 без сброса остальных данных.
- Покупка требует подтверждения. Сервер проверяет магазин, категорию, королевство, остаток, цену, баланс и место в инвентаре; после покупки списывает золото, добавляет предмет, уменьшает остаток и сохраняет состояние.
- Мастер может менять цену, остаток и скидку, а также добавлять собственные предметы.
- Торговец отвечает по фактическому ассортименту. Если настроен Groq или Anthropic API, используется ИИ; без ключа доступен базовый режим.
- Торг даёт скидку 5% один раз на конкретный предмет для конкретного персонажа.

## Перерасчёт цен
Каталог адаптирован под экономику кампании. Применены коэффициенты к исходным ценам: оружие ×3, броня ×4, щиты ×4, сапоги и перчатки ×2,5, книги заклинаний ×6. Мастер может изменить цену каждого товара в интерфейсе магазина. Стартовое золото автоматически не начисляется.

## Установка
1. Распакуйте ZIP.
2. Загрузите **содержимое архива** в корень репозитория GitHub, сохраняя папки `public` и `shops`.
3. Замените одноимённые файлы и подтвердите Commit changes.
4. `package.json` и `data.json` не заменяйте.

В архиве только файлы обновления. Существующие игровые данные `data.json` сохраняются.

## Что проверено
- Синтаксис всех обновлённых JavaScript-файлов.
- Все локальные импорты указывают на существующие файлы.
- В каталоге ровно 492 товара, ID уникальны, обязательные поля заполнены.
- В каждом из шести королевств по 82 товара.
- В восьми фиксированных локациях присутствует бронная мастерская.

Полный запуск сервера в этой среде не выполнялся: зависимости проекта (`express`, `socket.io`) здесь не установлены.

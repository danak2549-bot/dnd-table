# Магазины D&D — пакет обновления

Распакуйте архив и загрузите его содержимое в корень репозитория GitHub, сохраняя структуру папок. Файлы с существующими именами нужно заменить.

## Что добавлено

- Отдельное редактируемое поле «Золото» на листе персонажа. Игрок меняет баланс своего персонажа, мастер — выбранного персонажа.
- Старые персонажи без поля золота получают баланс `0`; остальные данные персонажей не сбрасываются.
- Нажатие на здания открывает соответствующие магазины: кузница — оружие; бронная мастерская — броня, щиты, сапоги и перчатки; библиотека — книги заклинаний; рынок и лавка — весь ассортимент.
- Каталог содержит 492 позиции: 180 видов оружия, 144 вида брони, 36 щитов, 6 видов сапог, 6 видов перчаток и 120 книг. В каждом из шести королевств — по 82 позиции.
- Покупка требует подтверждения, а сервер повторно проверяет магазин, товар, остаток и баланс. Золото списывается, предмет добавляется в инвентарь, остаток уменьшается.
- Мастер может менять цены, остатки и скидки, а также добавлять пользовательские товары в ассортимент текущего магазина.
- Торговец консультирует по фактическому ассортименту. Если на сервере настроен Groq или Anthropic API, ответы генерируются ИИ; без ключа работает базовый режим.
- Торг даёт не более 5% скидки один раз на предмет для каждого персонажа.

## Перерасчёт цен

Чтобы соотнести цены с текущим балансом персонажей (примерно 15–20 тыс. зм), базовые цены каталога увеличены:
- оружие — ×3;
- броня — ×4;
- щиты — ×4;
- сапоги и перчатки — ×2,5;
- книги заклинаний — ×6.

Мастер может изменить любую цену прямо в магазине. Стартовое золото автоматически не начисляется.

## Файлы в архиве

- `server.js` — серверная логика золота, магазинов, покупок и сохранения.
- `shops/catalog.js` — каталог товаров.
- `public/app.js` — открытие магазина по нажатию на здания.
- `public/shop.js` — интерфейс магазина и торговца (новый файл).
- `public/index.html` и `public/app.css` — окно магазина и стили.
- `public/sheet.js` — поле золота в листе персонажа.
- `public/scene-art.js` — отображение бронной мастерской.
- `README_SHOPS.md` — эта инструкция.

`package.json` менять не требуется. `data.json` не заменяется и не входит в пакет: существующие игровые данные останутся на месте.

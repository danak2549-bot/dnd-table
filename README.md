# Стол приключений

Запуск: `npm install`, затем `GROQ_API_KEY=... npm start` (бесплатный ключ с console.groq.com; нужен только для ИИ-мастера).
Открыть http://localhost:3000. «Создать комнату» делает вас мастером, игроки входят по коду.

Постоянные города
- Каменный Град (столица дварфов) и Деревушка Маунтайн рисуются по картинкам из `public/places/`; карты проходимости для жителей лежат в `places.js`.
- Стальград, Траун, Лорнэйдар, Хоббитон, Магор рисуются процедурно, но всегда одинаково (общий каталог в `server.js`).
- Любой другой город запоминается в комнате при первом открытии и потом не меняется.
- Культуры: люди, эльфы, дварфы (Марокко), полурослики (Мираж), орки (Магор). Жители города той же расы.

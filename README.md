# Стол приключений

Запуск: `npm install`, затем `GROQ_API_KEY=... npm start` (бесплатный ключ с console.groq.com; нужен только для ИИ-мастера).
Открыть http://localhost:3000. «Создать комнату» делает вас мастером, игроки входят по коду.

Что внутри
- Карта мира (public/world.jpg), приближение, рисованные персонажи по расам и монстры по названию.
- Поселения: ИИ открывает деревню, город, столицу, форт или порт. Здания, жители, доска объявлений создаются сами,
  вид зависит от культуры (люди, эльфы, дварфы, полурослики).
- Задания: доска объявлений, задания у жителей, актуальное задание у игрока.
- Лист персонажа, инвентарь, кубы, журнал событий.

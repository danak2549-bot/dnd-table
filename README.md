# Стол приключений

1. Положите ваши файлы листа персонажа в `public/`: `sheet.js` и `sheet.css` (оригиналы, без изменений).
2. `npm install`
3. `GROQ_API_KEY=... npm start` (бесплатный ключ с console.groq.com, нужен только для ИИ-мастера)
4. Откройте http://localhost:3000. «Создать комнату» делает вас мастером, игроки входят по коду.

Нужен хостинг с websocket (Render, Railway, VPS). Данные хранятся в `data.json`.

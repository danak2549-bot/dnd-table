# Остров отчаяния — три игровые карты

Добавлены три отдельные карты сверху в `public/island/`:
- `part1.webp` — Побережье Забвения;
- `part2.webp` — Древние Руины;
- `part3.webp` — Сердце Острова.

## Команды мастера
В поле «Спросить ИИ» напишите одну из команд:
- `ИИ, открой 1 часть локации задания на острове отчаяния`;
- `ИИ, открой 2 часть локации задания на острове отчаяния`;
- `ИИ, открой 3 часть локации задания на острове отчаяния`.

Поддерживаются также слова «первую», «вторую», «третью» и формулировка «часть 1/2/3».
Карта переключается сразу и становится видна всем игрокам. Возврат на карту мира — кнопкой «Покинуть локацию».


Лавки в этой сборке используют обычный каталог-таблицу: игроки видят ассортимент и покупают через серверную проверку. Чат с ИИ-торговцем отключён.

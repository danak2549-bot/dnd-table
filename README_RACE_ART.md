

## Объединение расовых иллюстраций
Добавлена отдельная система крупных иллюстраций для рас: человек, табакси, фея, аасимар и тень.
Файлы изображений находятся в `public/races/`. Остальные расы продолжают использовать существующую SVG-отрисовку.
Система подключена к листу персонажа и к спрайтам на карте. Магазины, каталог, серверная проверка покупок и существующие сцены не заменялись.
